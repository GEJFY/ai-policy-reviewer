## デモでの使い方

### 基本フロー

1. サンプルPDFをアップロード（または.txtファイルを手動変換）
2. AIレビューを実行
3. 検出された問題を確認
4. 承認/却下の判断

### 期待される検出結果

「就業規則_改定案_v2.txt」のレビューでは、以下のような指摘が期待されます:

```
【重要度: 高】用語統一
- 第1条: 「社員」→「従業員」に統一を推奨
- 第3条: 「社員」→「従業員」に統一を推奨

【重要度: 中】文体統一
- 第4条: 「採用します」→「採用する」（である体に統一）
- 第14条: 「なりません」→「ならない」（である体に統一）
- 第19条: 「なりません」→「ならない」（である体に統一）

【重要度: 中】表記統一
- 第6条: 「８時間」→「8時間」（半角数字に統一）
- 第10条: 「２日」→「2日」（半角数字に統一）

【重要度: 低】日付表記
- 附則: 「令和6年」→「2024年」または「令和6年（2024年）」

【重要度: 低】曖昧表現
- 第5条(4): 「その他当社が指定する書類」の具体化を検討
- 第11条(5): 「等」の具体化を検討
```
