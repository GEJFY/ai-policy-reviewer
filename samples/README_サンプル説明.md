```bash
cd backend
python -m scripts.generate_demo_pdfs
```

または `demo_setup.bat` を実行すると、デモデータ投入とPDF生成が一括で行われます。

## デモでの使い方

### 基本フロー

1. `demo_setup.bat` を実行（デモデータ投入+PDF生成+サービス起動）
2. ブラウザで http://localhost:3030 を開く
3. サイドメニュー「文書管理」からサンプルPDFをアップロード
4. AIレビューを実行（全20チェック項目を選択）
5. 検出された問題を確認
6. 承認/却下/保留の判断
7. レポート出力

### 期待される検出結果（就業規則）

```text
【重要度: 高】用語統一
- 第1条: 「社員」→「従業員」に統一を推奨
- 第3条: 「社員」→「従業員」に統一を推奨
- 第42条: 「社員」→「従業員」に統一を推奨

【重要度: 高】法的要件
- 第13条: 時間外労働の上限（月45時間/年360時間）の明記が必要

【重要度: 中】文体統一
- 第6条: 「採用します」→「採用する」（である体に統一）
- 第31条: 「なりません」→「ならない」（である体に統一）
- 第58条: 「なりません」→「ならない」（である体に統一）

【重要度: 中】表記統一
- 第11条: 「８時間」→「8時間」（半角数字に統一）
- 第17条: 「２日」→「2日」（半角数字に統一）

【重要度: 低】日付表記
- 附則: 「令和6年」→「2024年」または「令和6年（2024年）」

【重要度: 低】曖昧表現
- 第23条(5): 「等」の具体化を検討
- 第8条(10): 「その他当社が指定する書類」の具体化を検討
```

詳細な操作手順は `docs/DEMO_GUIDE.md` を参照してください。
